The Boreal Ripple mark: a boreal treeline reflected into concentric ripple arcs, in a single ink.

- `mark-ink-96/192/512.png` — the forest ink `#05331f` (`mark-ink`, light). Use it on every light surface.
- `mark-mint-96/192/512.png` — the mint ink `#a3d0be` (`mark-ink`, dark). Use it on the dark canvas.
- `favicon.svg` — the reduced mark (ripple arcs and shoreline only) in forest `#05331f` on a `#f7f6f2` rounded tile. Use it below about 40px, where the full mark's arcs merge.

Pick the smallest file at least twice the rendered size. The master is a 1024px raster with no vector original, so the PNGs are the canonical files. Leave a quarter of the mark's height clear on every side. No plate, gradient or shadow, and never a pillar hue.
