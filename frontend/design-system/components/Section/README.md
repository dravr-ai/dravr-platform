# Section

Section is a group on a settings or admin page: a 13px 600 title in the interface face, one optional `on-surface-variant` line, an optional action on the right, then its content 12px below.

It has no fill and no border, and there are 32px (`space-xl`) between sections, paid by the parent. Rows inside are divided by `ghost-border-faint`. The consumer provides `title`, `description`, `actions`, `children` and `headingLevel` (2 by default).
