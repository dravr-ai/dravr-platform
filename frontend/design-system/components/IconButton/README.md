# IconButton

IconButton is an icon-only action: a 32px square (44px on a coarse pointer) in `on-surface-variant` ink that turns `on-surface` over a `surface-container-low` hover.

The consumer provides one line icon as `children` and a required `aria-label`. Use it for the list's `+`, a header's gear or a row action. These are ink buttons, never filled `primary`.
