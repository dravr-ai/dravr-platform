# StatusIndicator

StatusIndicator is an 8px dot beside a word, so colour is never the only channel.

The dot is `success` (online), `outline-variant` (offline) or `error`, and the word is `on-surface-variant`. The same dot, in a pillar hue (`activity`, `nutrition`, `recovery`, `mobility`), marks a pillar beside its name. The consumer provides `status`, an optional `label` and a `size`.
