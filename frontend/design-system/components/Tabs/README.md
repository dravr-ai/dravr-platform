# Tabs

Tabs are text tabs, the Boreal filter language: sentence-case 13px 500 words 20px apart over a hairline, with the active one in `primary` ink and a 2px `primary` underline.

A mono count may sit beside a word, and each target is at least 44px. Pill chips are retired from athlete surfaces. The consumer provides `tabs` (`id`, `label`, optional `icon`, `badge` count, `disabled`), `activeTab`, `onChange` and `size`. Use `variant="underline"`.
