# TabHeader

TabHeader is how every athlete destination opens: one 52px row with the page's name in Schibsted Grotesk (18px, 600), an optional caption beside it (a count, never a sentence restating the title), the page's controls on the right, and a hairline below.

There is no icon square, no gradient and no second line. The consumer provides `title`, `description` and `actions` (a search, one primary action or a filter).
